# DayTrader Desk
Opening-range-breakout day-trading desk for US and NSE stocks: setup chart, exit plan, 10,000-replay Time Machine, position sizing, risk gate, bracket ticket and paper journal. Based on the MIT [day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill) method. Never places orders.

- **Web / PWA:** GitHub Pages (Actions → "Deploy to GitHub Pages"). Open on your phone → Add to Home screen.
- **Android APK:** Actions → "Build Android APK" → download `app-debug.apk` from Releases.
- **Local:** `python3 build.py` → open `www/index.html`.

Not financial advice. Most day traders lose money.
